# Escuela Sabática · 4.º trimestre 2026 · «Mi Biblia, mi tesoro»

Materiales para la clase de 9–12 años (Año C), del 3 de octubre al 26 de diciembre de 2026.

## Contenido

```
lecciones/   → libro de lecciones del alumno (PDF, versión comprimida para la web)
misioneros/  → historias misioneras para niños del trimestre (PDF) y presentación de Croacia (PPTX)
juegos/      → los 26 juegos de detectives (una lección y una misión por sábado)
```

## Juegos

Abre `juegos/index.html` (el «Archivo de casos»): destaca solo los juegos del próximo sábado y lista todas las semanas.
Cada sábado va primero la misión (caso impar) y después la lección (caso par).

Versión en línea, instalable como app en el móvil:
https://joseomarcabanillasleon.github.io/escuela-sabatica/
